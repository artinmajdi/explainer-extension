Choose your AI

Choose Gemini Nano or download a WebLLM model to explain text on your device.

Supported languages

Model author’s language details ↗

Language coverage is reported by the model author. Quality varies by language and model size. Prefer 1.5B for clearer explanations; the compact 0.5B model is less reliable. Requires WebGPU with shader-f16 support. Model files download from Hugging Face and are cached in this browser; explanations run on your device. No API key or separate app needed. WebLLM supports passages up to 1,800 characters including optional context.

Select a model and download it to begin.

Chrome downloads the model once. After setup, explanations work offline. Pictures still use Wikimedia if you enable them. There is no automatic cloud fallback.

Checking local AI availability…

Automatic on websites

Select text on any supported website after setting up your AI model. No right-click activation is needed. Pause Explainer or disable individual sites using the toolbar. Chrome’s extension site-access settings can further restrict where it runs.
